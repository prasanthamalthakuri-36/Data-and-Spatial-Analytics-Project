# QGIS — Darjeeling Administrative Units

## Overview

This folder contains the QGIS project and spatial data used to create the custom administrative-unit map of Darjeeling district.

The spatial layer was prepared from government geographic data and organized into the administrative units required for the study.

## Administrative Units

The final layer contains 12 administrative units:

- Darjeeling - Pulbazar
- Darjeeling Municipality
- JoreBunglow - SukhiaPokhri
- Kharibari
- Kurseong
- Kurseong Municipality
- Matigara
- Mirik
- Mirik Municipality
- Naxalbari
- Phansidewa
- Rangli - Rangliot

## Spatial Data

The repository contains:

- `DARJEELING.shp`
- `DARJEELING.shx`
- `DARJEELING.dbf`
- `DARJEELING.prj`
- `DARJEELING.cpg`
- `Darjeeling Administration Units.geojson`

## QGIS Project

`Darjeeling Administrative Units.qgz`

The project contains the layer configuration, symbology and labels used to visualize the administrative units.

## Coordinate Reference System

**WGS 84 — EPSG:4326**

## Purpose

The prepared spatial layer provides a clean polygon-based representation of Darjeeling's administrative units for geographic visualization and analysis.
