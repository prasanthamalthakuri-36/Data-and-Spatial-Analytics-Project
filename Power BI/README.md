# Power BI — Darjeeling Education Analytics

## Overview

This folder contains the Power BI dashboard developed to analyse school education data for Darjeeling district, West Bengal.

The dashboard examines:

- Student enrolment
- Enrolment by gender
- Enrolment by school stage
- Educational infrastructure availability
- Year-wise trends
- Administrative-unit comparisons
- Infrastructure–enrolment correlation
- Infrastructure performance and improvement rankings
- Enrolment strength and improvement rankings

## Dashboard Pages

### 1. Geography Overview

Provides a spatial overview of schools across the administrative units of Darjeeling district.

### 2. Enrolment Overview

Presents year-wise student enrolment trends, including boys and girls.

### 3. Enrolment by Stage

Analyses enrolment across:

- Primary
- Upper Primary
- Secondary
- Higher Secondary

with gender-wise comparisons.

### 4. Infrastructure Overview

Shows year-wise availability of different school infrastructure indicators.

### 5. Infrastructure by Year

Enables comparison of infrastructure availability across years, administrative units and school categories.

### 6. Correlation Analysis

Uses a scatter diagram to examine the relationship between infrastructure availability and student enrolment.

The analysis includes Pearson correlation and p-value measures.

### 7. Infrastructure Rankings

Ranks administrative units according to:

- Infrastructure availability as of 2019–20
- Infrastructure improvement from 2015–16 to 2019–20

### 8. Enrolment Rankings

Ranks administrative units according to:

- Enrolment strength as of 2019–20
- Enrolment improvement from 2015–16 to 2019–20

`Darjeeling Master Project.pbix`

## Key Dimensions

The dashboard uses analytical dimensions including:

- Academic year
- Administrative unit
- School category
- Infrastructure type
- Gender
- School stage

## Statistical Analysis

The correlation analysis uses:

- Pearson correlation coefficient (`r`)
- p-value

to quantify the association between infrastructure availability and enrolment.

Correlation results should be interpreted as measures of association and not as evidence of causation.
