# Data

This directory contains the datasets associated with the Darjeeling District Education Analytics project.

## Data Organization

- `Raw/` — source datasets obtained from government data sources.
- `Cleaned/` — datasets prepared through the Python data-preparation workflow for subsequent analysis in Power BI.

## Data Availability

Source datasets may not be redistributed through this repository where their publication, licensing, size, or other restrictions apply.

Where applicable, the repository provides documentation describing the source data and the preparation methodology.
